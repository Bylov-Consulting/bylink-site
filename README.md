# bylink-site

Public website for the Bylink apps for Shopify (Business Central, Microsoft AppSource), served by GitHub Pages at
https://bylink.bylov.net/.

The URLs below are compiled into the apps' `app.json`, so do not rename or move these pages:

| app.json field | URL |
|---|---|
| `url` | https://bylink.bylov.net/ |
| `privacyStatement` | https://bylink.bylov.net/privacy.html |
| `EULA` | https://bylink.bylov.net/terms.html |
| `help` | https://bylink.bylov.net/help/order-sync.html, `return-handling.html`, `pre-orders.html`, `tag-routing.html`; libraries `help/index.html` |
| `logo` | `assets/logo-216.png` (216×216 PNG, copied into each app folder) |

Plain static HTML with one shared stylesheet in `assets/style.css`. `.nojekyll` turns off Jekyll processing.
