Getting started

What every Bylink app needs before you switch it on.

Requirements

  • Business Central online, version 28 or later, with Microsoft's Shopify Connector set up for your shop.
  • A custom app in Shopify (Shopify admin, Settings, Apps and sales channels, Develop apps) with the Admin API access scopes the apps you use need. The scopes are listed on each app's page.

The two library apps

Every Bylink app installs two library apps with it. You do not buy them separately.

Bylink Shopify Admin API

Calls the Shopify Admin API (GraphQL) for the Bylink apps with your shop's own credentials. To set it up:

  1. In Shopify, create the custom app, grant the scopes, and install it on the shop.
  2. In Business Central, open the Shopify Shop Card and enter the Admin API credentials for the shop. They are kept in isolated storage.
  3. Where an app writes metafields, create the metafield definitions in Shopify and add the matching rows to the Shopify Metafield Definitions page in Business Central (same namespace, key and owner type, Enabled).

Every call is written to the Shopify API Log in Business Central, where administrators can see request, response and status.

Permission set: Shpfy Admin API BYL for whoever sets up credentials and metafield definitions.

Bylink Shopify Feature Flags

Adds a Feature Flags part to the Shopify Shop Card. Each Bylink feature is switched on there, per shop. An installed app does nothing for a shop until its flag is on, so you can roll out one shop at a time.

Users who add or delete shops need Shpfy Feat Flags BYL.

Before production

Try every feature in a sandbox copy of your production environment against a development or test store in Shopify first. Sandbox use is free.
