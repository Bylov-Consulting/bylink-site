Getting started

What every Bylink app needs before you switch it on.

Requirements

  • Business Central online, version 28 or later, with Microsoft's Shopify Connector set up for your shop.
  • For Order Sync, Return Handling and Pre-Orders: an app for your store created in Shopify, with the Admin API access scopes listed on each app's page. Tag Order Routing does not call Shopify and needs no app.

The two library apps

The Bylink apps install these library apps with them, as needed. You do not buy them separately.

Bylink Shopify Admin API

Calls the Shopify Admin API (GraphQL) for Order Sync, Return Handling and Pre-Orders with your shop's own credentials. To set it up:

  1. In Shopify, create an app for your store, grant it the scopes, install it on the store, and copy its Client ID and Client secret.
  2. In Business Central, open the Shopify Shop Card. In the Shopify Admin API group, check the Shopify URL, choose Manage API Credentials, and enter the Client ID and Client Secret. They are kept in isolated storage. Test API Connection on the Shop Card checks them.
  3. Where an app writes metafields, create the metafield definitions in Shopify and add the matching rows to the Shopify Metafield Definitions page in Business Central (same namespace, key and owner type, Enabled).

Every call is written to the Shopify API Log (an action on the Shop Card), where administrators can see request, response and status.

Permission set: Shpfy Admin API BYL for whoever sets up credentials and metafield definitions.

Bylink Shopify Feature Flags

Adds a Shopify Feature Flags part to the Shopify Shop Card. Order Sync, Pre-Orders and Tag Order Routing are switched on there, per shop; Return Handling is switched on with a field on the Shop Card instead. An installed app does nothing for a shop until it is switched on, so you can roll out one shop at a time.

Users who add or delete shops need Shpfy Feat Flags BYL.

Before production

Try every feature in a sandbox copy of your production environment against a development or test store in Shopify first. Sandbox use is free.
