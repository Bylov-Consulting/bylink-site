Bylink Return Handling for Shopify

A customer returns goods. Business Central makes the paperwork and Shopify pays the refund.

What it does

Return opened in Shopify → sales return order in Business Central → goods received (return receipt posted) → Business Central asks Shopify to refund the received lines → credit memo in Business Central, posted by finance.

Each return is a row on the Shopify Return Pipeline page in one of these stages: Imported, Order Created, Refund Requested, Credit Memo Created, Completed (or Skipped). A row that stops is Blocked with a reason, the error and a hint. Business Central never sends a refund amount; Shopify computes it from the received lines.

Refunds without a return go to the Shopify Connector's own Auto Create Credit Memo process.

Setup

Shopify custom app scopes: read_returns, write_returns, plus the order scopes the connector uses. On the Shopify Shop Card:

FieldValue
Return and Refund ProcessReturn Order BYL. Any other value and the app does nothing for the shop.
Default Return LocationThe location that receives returns. Blank blocks every return.
Return Import From DateYour go-live date. Returns on older orders are skipped.
Return Stale After DaysDays a row may wait for a refund or credit memo before it is flagged Stalled. 0 means 7.
Return Refund Difference AccountG/L account for any difference between Shopify's refund and the value credited. Blank blocks such rows.
Use Return No. as Document No.Gives the return order the Shopify return name as its number.

Before you switch on, make sure there are no unprocessed refunds for the shop.

Daily work

Sync Orders from Shopify must keep running: each run creates return orders, flags stalled rows and turns refunds into credit memos. Posting a return receipt asks Shopify for the refund straight away. On the pipeline page:

  • Retry: fix the cause first; the next sync runs the stage again.
  • Mark Resolved: you handled it by hand; the sync leaves the row alone. Reopen undoes it.
  • Open in Shopify, Return Order, Credit Memo: navigation.

Common block reasons

ReasonWhat to do
Quantity Exceeds SoldThe return has more than the order had. Correct the return in Shopify.
Return Location MissingSet Default Return Location on the Shop Card, then Retry.
Partial ReceiptReceive the rest or reduce the line, then Retry.
Document MissingThe return order was deleted. Handle by hand and Mark Resolved.
Canceled In ShopifyThe return was cancelled. Delete the return order if not needed.
Foreign Refund ExistsSomeone refunded in Shopify by hand. Check the amounts and Mark Resolved.
StalledThe row waited longer than Return Stale After Days. Check the receipt or credit memo.

Permissions

Shpfy Returns BYL and sales document rights for the user who runs the sync and for the pipeline operators. Users who post return receipts also need Shpfy Returns BYL for the immediate refund; without it the next sync sends the request.

Known limits

  • Shop currency only; orders in another presentment currency are refused.
  • Releasing the return order from the app skips approval workflows.
  • Exchanges, return reason mapping and restocking fees are not handled.
